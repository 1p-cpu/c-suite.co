Governance · IPO · Succession

管理体制構築 / 上場準備 / 承継設計会社の次のステージを、現在の経営判断と接続しながら準備する。

内部管理体制の整備・IPO準備・事業承継・EXITを見据えた経営設計を一貫してサポートします。
承継・上場・資金調達は準備が早いほど選択肢が広がります。中長期を今の経営と接続します。

Scope

支援領域

  • A

    内部管理体制・内部統制の構築

    売上規模に管理体制が追いついていない会社に対し、経営管理（計画・予実・会議体）、規程・業務フロー、職務分掌、内部統制の整備を、実務レベルで支援します。

  • B

    IPO準備・上場支援

    プロマーケット上場を含め、上場準備課題の整理、資本政策の論点整理、決算体制・管理体制の構築、監査法人・証券会社対応を、会社側の立場で支援します。

  • C

    事業承継・経営移行

    現経営者から後継者へ、経営そのものを移行するプロセスを支援します。株式・税務の手続きだけでなく、承継後に会社が自走できる体制づくりまで一貫して伴走します。

  • D

    EXIT戦略・M&A・グループ再編

    M&A・グループ再編といった経営の転換点を、財務・組織・戦略の観点から準備します。「その日」に向けた逆算設計を行います。

グループでの連携：M&A・FA（片側支援）、IPO・上場準備、内部統制・J-SOX、内部監査の専門アドバイザリーは、グループ会社の ザクトリン合同会社 ↗ が提供します。ご相談内容に応じて、最適な体制でご提案します。
Process

進め方

  1. 現状整理（初回面談・60分・無料）

    会社の現状、目指す出口（上場・承継・M&A）、管理体制の課題をお聞きし、論点と優先順位を整理します。

  2. ロードマップの策定

    目標時期から逆算し、誰が・いつまでに・何を整備するかを計画に落とし込みます。

  3. 実行支援

    管理体制・内部統制・決算体制・組織の整備を、会社側の立場で実行支援します。必要に応じてグループ会社・外部専門家と連携します。

料金は企業規模・支援範囲・関与頻度により個別にお見積りします。
